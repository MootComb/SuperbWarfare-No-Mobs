# SuperbWarfare 枪械 HUD 设计参考 v1.1

日期：2026-10-18。此版本在已认可的四角资源框、组合资源、弹种队列和 AUI 武器图标动画基础上，加入超级星星炮的青色虚拟备弹，并修正中轴、左边界和右对齐规则。

`ammo-hud-v1` 目录名保留为稳定引用入口，当前内容版本为 **v1.1**。以本版 DESIGN.md 的对齐规定为准。

## 文件入口

- `preview.html`：完整、可离线打开的交互预览，图片、样式和脚本已内嵌。用浏览器打开即可。
- `source.html`：可编辑的 HTML 片段源稿；供后续对话阅读、修改和重新导出。
- `DESIGN.md`：布局、数值语义、状态优先级、动画参数及实施约束。实施前先读此文件。
- `overview.png`：八种场景的静态总览，包含虚拟备弹，适合直接作为图片参考。

预览操作：

1. 选择“武器情况”，或点击“切换武器”查看武器图标的 500ms 缩放淡入。
2. 有弹匣的场景可点击“开始换弹”；图标持续闪烁。点击“完成换弹”结束闪烁，并重播缩放淡入。
3. 多弹种场景使用左右按钮观看图标队列。勾选“慢放”可观察过渡。
4. 在 Taser 或组合资源场景中，可勾选“副资源不足”查看对应符号的不足标记。
5. 超级星星炮场景默认显示 `300`、`3200` 与右上角 `+99`。开始换弹时演示换弹前的 `299`、`3300`，完成后消费一颗下界之星，其中 1 发补满弹匣、99 发成为虚拟备弹。

“开始/完成换弹”是原型控制，不是游戏内新增按钮。预览中的弹量和部分资源、模式组合是示意，不代表各枪实际配置。

## 在其他对话中引用

同一工作区可以直接发送：

> 请读取 `D:\SuperbWarfare\docs\design\ammo-hud-v1\README.md` 和 `DESIGN.md`，并以该目录的 `preview.html`、`source.html`、`overview.png` 为设计参考。按 DESIGN.md v1.1 的约束实施 AmmoBarOverlay/AUI HUD。保留基础 HUD 风格、字体、枪械图标和弹量语义，严格遵守中轴、弹量列左对齐、键位右对齐和 A/B 居中规则。保留右上角青色虚拟备弹，资源座不重复显示数量。特别注意 AmmoType 与同组 Ammo 来源的区别，以及 Taser 的电极＋能量组合。浏览器预览代码不是可直接替换 AUI 的生产模板。

其他工作区可复制整个 `ammo-hud-v1` 目录，或自行压缩后附上。若只需要实现依据，可附上 `DESIGN.md` 和 `overview.png`；动态效果以 `preview.html` 为准。

本目录只保存设计资料，没有实施或修改模组 HUD 源码。
